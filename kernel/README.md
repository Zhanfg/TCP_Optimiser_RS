# Kernel module bundle

This directory is generated by `scripts/build-kernel-modules.sh`.

The first supported build target is **Android 15 GKI 6.6 / arm64**. The build
produces real loadable kernel modules for:

- `tcp_bbr.ko` — kernel-tree BBR (BBRv1 on the selected Android common tree)
- `tcp_bbr3.ko` — BBRv3 compatibility module
- `sch_fq.ko`
- `sch_codel.ko`
- `sch_fq_codel.ko`
- `sch_cake.ko`
- `sch_pie.ko`
- `sch_fq_pie.ko`

The generated `manifest.json` records the KMI family, architecture, exact
kernel source revision, BBRv3 source revision, relative file path and SHA-256
for every module.

The runtime loader deliberately refuses unsafe path traversal and hash
mismatches. It never uses `insmod -f`. A module rejected by the running
kernel for KMI, symbol-version or signature reasons remains rejected.

BBRv2 is intentionally not emitted by this first build target. A generic
out-of-tree `tcp_bbr2.ko` is not equivalent to full BBRv2 on kernels that lack
the required TCP-core changes; it will be added only for kernels whose core
stack is known to provide the required API/behavior.
