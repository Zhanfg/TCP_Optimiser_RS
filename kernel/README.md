# Kernel module bundle

This directory is generated by `scripts/build-kernel-modules.sh`.

The current verified build matrix targets arm64 Android GKI families whose
kernel versions are covered by the BBRv3 compatibility implementation:

- Android 12 / Linux 5.10
- Android 13 / Linux 5.15
- Android 14 / Linux 6.1
- Android 15 / Linux 6.6

Each build produces real loadable kernel modules for:

- `tcp_bbr.ko` — kernel-tree BBR
- `tcp_bbr3.ko` — BBRv3 compatibility module
- `sch_fq.ko`
- `sch_codel.ko`
- `sch_fq_codel.ko`
- `sch_cake.ko`
- `sch_pie.ko`
- `sch_fq_pie.ko`

The build uses a full GKI kernel build so `Module.symvers` and
`CONFIG_MODVERSIONS` CRCs are available. BBRv3 is additionally audited for
exported-symbol resolution, and every shipped KO is checked against the
Android arm64 GKI KMI symbol lists.

The generated `manifest.json` records the **full KMI version**, including the
KMI generation (for example `6.6-android15-8`), architecture, exact kernel
source revision, BBRv3 source revision, relative file path, and SHA-256 for
every module. Kernel sublevel differences are intentionally not used as a
selection key because Android GKI compatibility is defined by KMI + symbol
versioning.

The runtime loader requires an exact KMI match, verifies SHA-256 before
loading, and never uses `insmod -f`. A module rejected by the running kernel
for KMI, symbol-version, protected-export, or signature reasons remains
rejected.

Release builds merge all verified KMI artifacts into the Magisk/KernelSU ZIP.
Ordinary source CI does not rebuild four full kernels on every main-branch
push.

BBRv2 is intentionally not emitted as a generic KO. Full BBRv2 relies on TCP
core changes outside the congestion-control source file; it will be provided
only for kernel targets whose TCP core is known to contain the required
support.
